# CFR Core and Trainer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Rust workspace in `solver/` that trains a heads-up 100 bb NLHE strategy with MCCFR overnight, exports it as a strategy file and measures it with local best response and a baseline match.

**Architecture:** `mallorca-core` is a pure library (cards, evaluator, isomorphism, abstraction, explicit betting tree, generic external sampling MCCFR with DCFR, strategy file, measurement). `mallorca-trainer` is the CLI that does I/O, threads and timing. Infosets are `(node, bucket)` offsets into flat atomic `f32` arrays.

**Tech Stack:** Rust stable (pinned in `solver/rust-toolchain.toml`), `serde` + `toml`, `sha2`, `clap`, `ctrlc`. Node 24 for the evaluator golden fixture script.

**Spec:** `docs/superpowers/specs/2026-10-23-cfr-core-design.md`

## Global Constraints

- New code lives in `solver/`, plus `web/tools/evaluator-golden/`, `.github/workflows/solver-ci.yml`, root `CLAUDE.md`, `.gitignore`. Do not touch `web/src/engine`, `web/src/game`, `web/src/ui` or the Java modules.
- No comments in code or config, in any language.
- `mallorca-core` uses no `std::time`, no `std::fs`, no `std::env`, no thread-local or global RNG and must build for `wasm32-unknown-unknown`. Randomness enters as a `&mut Rng` argument. Threads, files and clocks live in `mallorca-trainer`.
- Cards are `u8` 0..51, `rank * 4 + suit`, rank 0..12 for `2..A`, suit 0..3 for `c d h s`; text form is two characters, rank `23456789TJQKA`, suit `cdhs`.
- Chips are `u32`. Blinds 10/20. The blueprint is trained at a 2000 chip (100 bb) effective stack; real play can be deeper (top-up to 2000 for the shorter seat only), which measurement covers with `--stack`. Bets are "raise to" the street total.
- Hand ranks: `u16` 0..7461, 0 the worst high card, 7461 a royal flush, equal to `pheEvaluator.rank` in `web/src/equity/evaluator.ts`.
- Strategy file: little-endian, magic `MLCS`, `format_version` 1, probabilities `u8` summing to exactly 255 per infoset.
- TDD: the failing test first. Never loosen a tolerance, add `#[allow]`, or delete an assertion to get green.
- Before every commit, from `solver/`: `cargo fmt --all`, `cargo clippy --all-targets -- -D warnings`, `cargo test`. Run `git branch --show-current` first; the branch is `feat/cfr-core`.
- Conventional commits with scope `solver` (`feat(solver): ...`), each ending with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Decisions taken while planning

- The evaluator is written from scratch on the idea of a rank-multiset index plus a flush table, not ported from HenryRLee or `phe`. The 7462 classes have one canonical order, so any correct evaluator matches `phe` and no licence question arises; the golden test proves the match.
- The hand isomorphism is implemented from Waugh's paper ("A Fast and Optimal Hand Isomorphism Algorithm", 2013), not copied from his C code.
- Bucket percentiles count canonical classes, not raw combos.
- MCCFR is generic over a `Game` trait so Kuhn and Leduc test the same code the real game uses.
- The parallel driver lives in the trainer: the core exposes one iteration; the trainer runs it in `std::thread::scope` workers.
- LBR equity: exact on the river and turn, 200 sampled turn and river runouts on the flop.
- Measurement reads the full strategy file (`--streets all`), so it also tests the file format.

## Review Focus

- A stack too short for the preset sizes after a 3-bet or 4-bet pot: postflop actions collapse to check and all-in, no duplicate or illegal child. Test in Task 4.
- Both seats all-in before the river: the tree goes straight to a showdown terminal, the deal runs out the board, no decision nodes follow. Test in Tasks 4 and 7.
- A checkpoint truncated by a crash or Ctrl-C, or one from another preset: `train` stops with an error naming the file, never panics, never resumes from it. Checkpoints are written to a temp file and renamed. Test in Task 8.
- An infoset that was never visited or has a near-zero tail, such as `[0.9990, 0.0005, 0.0005]`: quantization still sums to 255, the unvisited one is uniform. Test in Task 9.
- A strategy file with a wrong magic, unknown version, short body or mismatched fingerprint: the reader returns an error, never panics. Test in Task 9.
